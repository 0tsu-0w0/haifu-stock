# ログインのメールの送り方(備忘録)

2026-10-10 時点のメモ。サークル主のログインで届くメールの差出人を、個人のメールアドレスにしないための方法をまとめる。

## いまの状態
- Supabase の **Authentication → Emails → SMTP Settings** で、サークル主の個人の Gmail(アプリパスワード)を送り元にしている。差出人の名前は「頒布レジ」
- メールの本文はコード(数字)だけ。リンクを入れると、メールの安全確認の機能(セキュリティソフトやブラウザの拡張機能)が先に開いて使い切ってしまうため
- コードの桁数は Supabase の **Authentication → Sign In / Providers → Email → Email OTP Length** で 6 にしている(アプリは 6〜10 桁を受け付ける)
- **困っていること**: 届くメールの差出人が、個人の Gmail のアドレスになる

### 前提
- Gmail の SMTP は、ログインしたアカウントのアドレスしか差出人にできない。差出人だけを書き換えることはできない
- Supabase 標準のメール送信(noreply@mail.app.supabase.io)に戻すと、テンプレートを編集できず、リンクだけのメールになる。リンクは安全確認の機能に使い切られることがあるので、戻さない

## 方法1. 送信専用の Gmail を作る(おすすめ・無料)
差出人の例: `haifu.reji.app@gmail.com`

1. 新しい Google アカウントを作る(送信専用。普段のメールには使わない)
2. そのアカウントで **2段階認証プロセス** をオンにする
3. https://myaccount.google.com/apppasswords で、アプリ名 `haifu-stock` のアプリパスワード(16文字)を作る
4. Supabase の **Authentication → Emails → SMTP Settings** を差し替えて保存する
   | 項目 | 値 |
   |---|---|
   | Sender email | 新しいアカウントのアドレス |
   | Sender name | 頒布レジ |
   | Host | `smtp.gmail.com` |
   | Port | `465` |
   | Username | 新しいアカウントのアドレス |
   | Password | 3 のアプリパスワード(空白なし) |
5. 個人の Gmail で作ったアプリパスワード `haifu-stock` は、https://myaccount.google.com/apppasswords で削除する
6. ログイン画面からメールを送り、差出人が新しいアドレスになっていることを確かめる

- **よいところ**: 無料。15分ほど。アプリ側の変更はいらない。個人のアドレスを出さずに済む
- **気をつけること**: Gmail の1日の送信数には上限がある(このアプリの使い方なら足りる見込み)。新しいアカウントは放置すると使えなくなることがあるので、たまにログインしておく。条件は Google の案内で確かめる

## 方法2. 自分のドメインとメール送信サービスを使う(有料・見た目がきちんとする)
差出人の例: `no-reply@自分のドメイン`

1. ドメインを取る(年に千数百円ほど。Cloudflare などで取れる)
2. メール送信サービス(Resend など)に登録し、そのドメインを追加する
3. サービスの案内どおりに、ドメインの DNS に SPF・DKIM などのレコードを入れて、ドメインの確認を済ませる
4. サービスの SMTP の情報(ホスト・ポート・ユーザー名・パスワードや API キー)を、Supabase の SMTP Settings に入れる。Sender email は `no-reply@自分のドメイン`
5. ログイン画面からメールを送り、届くこと・迷惑メールに入らないことを確かめる

- **よいところ**: 差出人が独自ドメインになり、迷惑メールにも入りにくい。送信数の上限もサービスの無料枠で足りることが多い
- **気をつけること**: ドメイン代がかかる。DNS の設定が要る。無料枠や料金は変わることがあるので、使う前に各サービスの案内で確かめる

## 方法3. Google でのログインにする(メールを送らない・無料)
アプリ側は対応済み。Supabase で Google が有効になると、ログイン画面に「Google でログイン」が出る。

1. Google Cloud Console でプロジェクトを作る
2. 「API とサービス → OAuth 同意画面」を設定する(アプリ名: 頒布レジ)
3. 「認証情報 → OAuth クライアント ID」(種類: ウェブアプリケーション)を作る
4. 「承認済みのリダイレクト URI」に次を入れる
   ```
   https://jrzbtjlpufezxqkrntoj.supabase.co/auth/v1/callback
   ```
5. できたクライアント ID とシークレットを、Supabase の **Authentication → Sign In / Providers → Google** に入れて有効にする
6. Supabase の **Authentication → URL Configuration → Redirect URLs** に `https://haifu-stock.vercel.app/login` があることを確かめる
7. ログイン画面で「Google でログイン」を押して、ログインできることを確かめる

- **よいところ**: メールが届かない・使い切られる問題が起きない。同じメールアドレスの Google アカウントなら、今のアカウントのまま使える見込み
- **気をつけること**: Google アカウントを持っていない人は使えないので、方法1 か 2 のメールのコードも残しておく。ログインは、始めたのと同じブラウザで完了する必要がある(iPhone のホーム画面のアプリでは、Safari に移ってしまうことがある)

## どれを選ぶか
- まず **方法1** で個人のアドレスを出さないようにする
- サークルの外に配るなど、きちんと見せたくなったら **方法2** に移す
- メールのやりとり自体を減らしたいなら **方法3** を足す(1 か 2 と併用)
